# BayesNEGF

## About

Bayesian inference on single-molecule data for quantum transport. Uses dynamic nested sampling (dynesty) and non-equilibrium Green's functions (NEGF) to parameterise transport models and extract transmission spectra.

### Current Version

Barebones implementation in v0.0.0 similar to the initial scripts found in our recent work.  
We plan to extend this to a more user friendly general framework in the future.
